## 已定（2026-11-04）

| 决定 | 原因 |
|---|---|
| 放弃 Electron 版 tandem，用 Tauri 重新写 | 目标是更低内存和更快启动。实测见 [measurements](measurements/2026-11-04-startup-and-memory.md) |
| 项目名为 Tandem，沿用原有图标 | 用户决定 |
| 只复刻界面，不是 fork，不跟进 Cindy 上游 | 重写后上游合并已无意义 |
| 界面尽量复刻 Cindy，品牌素材除外 | 用户决定。名称、Logo、角色形象不在许可范围内 |
| 任务数据走原生会话 | 沿用 loom 的方向。原生方案本身的问题（单写入者、外部状态）会留下，要在这里解决 |
| 不双写：不维护自己的会话记录，读取时把原生格式转成界面格式 | 存两份就要处理同步、回退分支和终端续聊带来的不一致。只认 CLI 的文件，从终端续聊和删掉 Tandem 都不会丢东西，实测读取也够快 |
| 本地只存可以丢弃的数据：界面状态（置顶、别名），以及需要时可重建的索引 | 这些内容 CLI 不保存，丢了也不影响任务 |
| 旧 fork 的 GitHub 仓库改名为 `tandem-cindy`，新仓库用 `mingzaily/tandem` | 把名字留给新项目 |
| 手机端用 PWA，加自建中转，部署到用户的腾讯云服务器 | 官方 App 依赖 Cindy 账号和协议，而且 iOS 自建 App 需要付费开发者账号 |
| 仓库顶层分 `docs`、`desktop`、`pwa`、`relay` | 用户决定 |
| 所有规范放在 `docs/` | 用户决定 |
| Token 取一次快照后归本仓库维护 | Cindy 的生成器绑定了它的桌面端路径 |
| 不再使用 Tandem 的旧数据，历史用 Git 引用保留 | 旧分支和 loom 的提交只存在本地，必须带过来，见 [仓库地图](dev-rules/repo-map.md) |
