# 凭证与本地存储

> **状态**：权威
> **读取时机**：处理凭证、写文件或新增持久化数据之前

## 凭证

- 用户凭证、令牌、私钥和 CLI 登录文件不进入仓库、日志和测试数据。
- Tandem 不读取、不保存 CLI 的登录凭证，登录态由 CLI 自己管理。

## 用户的文件

- 不写用户的 CLI 配置文件，清单见 [核心产品原则](../product-rules/core-product-principles.md)。
- 会话文件只读，只有 CLI 自己能写。

## Tandem 自己的数据

- 只存放可以丢弃的数据，删除后不能丢任务。
- 放在系统分配的应用数据目录（`com.mingzaily.tandem`）。

## 测试和临时文件

- 测试用 `tempfile` 创建目录，不写用户目录和仓库。
- 日志不记录任务内容。

## 页面的本地存储

页面用 `localStorage` 保存可以丢弃的内容（`lib/preferences.ts`）：输入框的模型、推理强度和权限模式，上次读到的模型列表和用量，各模型的上下文窗口大小。读写都要容错，清空后功能不受影响，不能放任务内容和凭证。
