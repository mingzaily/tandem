# 2026-11-05：队列、输入区与底栏协调

参考 Cindy 的 `PendingQueuePanel.tsx`、`ChatInput.tsx` 与 `CCAgentSessionView.tsx`，保留合并卡片、常显队列操作和暂停文案，整理三块区域的信息层次。

- 队列标题采用与拖动把手相同的 24px 图标盒，列表改用单侧滚动槽；标题与把手的实测中心差为 1px，来自行边框。工具栏和卡片外底栏统一采用 12px 左右内距，正文编辑保持 16px。
- 排队时在编辑区显示“本条消息将加入待发送队列”，文字独立于 placeholder，通过 `aria-describedby` 关联输入框，有草稿时仍可阅读。编辑队列消息时使用编辑状态说明。
- 编辑行保留“编辑中”，取消入口集中在编辑区；保存按钮显示“保存修改”。保存和取消保留原草稿、附件和入队选项，取消后回到草稿输入框。保存期间禁用取消，保持提交顺序。
- 目录、用量和上下文继续使用卡片外的 12px 次要信息行；文件编辑摘要保留在卡片上方。
