# 2026-11-05：输入光标和输入框高度

参考本地 Cindy 的 `ChatInput.tsx`、`styles/globals.css`、`composerBlankPointerFocus.ts` 与 `useComposerSendFocusRestore.ts`。

Cindy 普通对话编辑卡片最小 86px，新建页 140px。Tandem 原来两处均为 94px；按本次用户要求，续聊改为最小 112px，新建页改为 140px。队列独立于编辑区的最小高度，双方共享外边框；文本框仍可自动增高到 240px 并内部滚动。

修改前通过调试脚本复现：点击嵌套的工具栏空白无法聚焦输入框，成功入队后输入框丢失焦点，原生光标使用默认正文色。现在编辑区空白保留原选区，发送按钮的指针操作保留输入焦点，短暂禁用结束后按归属恢复；发送期间主动选择其他控件或页面区域时保持新焦点。原生光标统一使用已有蓝色 `--caret-accent`。
