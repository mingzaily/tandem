# 2026-11-05：消息区与输入区的过渡

原来的消息流与输入区上下排列。消息滚动到边界时会直接裁切文字，输入框上方缺少渐隐。

参考本地 Cindy 的 `CCAgentSessionView.tsx`、`useComposerOverlayMetrics.ts` 和 `MessageStream.tsx`，改为完整高度的消息滚动区与底部输入区叠放：上沿 32px 渐变、下方实色区、底部 20px 留白。输入区沿用宽度和左右边距，窄布局每侧为 10px。

`ConversationLayout` 用 `ResizeObserver` 实测状态、队列、授权卡片、输入框和页脚的总高度，并在绘制前更新消息流的 `paddingEnd` 与 `scrollPaddingEnd`。自动贴底时最后一行保持完整可见；查看历史时输入区增高保持原来的滚动位置。新建页沿用原来的布局。
