# 2026-11-05：模型菜单方向与默认模型

参考本地 Cindy 的 `ModelSelector.tsx`（`popoverSide = 'top'`）和 `morph-popover.tsx`：模型菜单向上展开，高度按上方可用空间收缩，模型列表内部滚动。

原来的通用弹层定位会在下方空间更大时翻转。现在模型菜单固定向上，权限、项目、上下文等其他弹层沿用原来的空间适配。默认标记使用“默认”文字标签，当前选择保持行高亮。

三种 CLI 已有各自的默认模型元数据：Claude 的 `initialize` 默认别名、Codex 的 `model/list.isDefault`、Pi 的临时进程 `get_state.model`。解析出的默认别名与真实模型合成一行，选中这一行保存 `model: null`，继续跟随 CLI 配置。选择其他模型只改变 Tandem 的发送选项。默认 ID 尚未解析时保留“跟随 CLI 配置”入口，空 ID 保持各模型独立，CLI 未报告默认值时保持未知。
