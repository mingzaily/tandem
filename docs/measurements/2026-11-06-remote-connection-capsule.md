# 手机连接胶囊验收

日期：2026-11-06。范围：桌面端新建页与任务输入区的手机连接提示。

## 实现与审查

对照 Cindy 的 `features/remote-device/ControlledBanner.tsx` 和 `CCAgentSessionView.tsx`，采用 28px 胶囊、12px 文字和呼吸点。Tandem 读取现有 `remote_state`，订阅 `remote-changed`；设备完成加密握手后显示连接提示。

- 单设备显示名称和“撤销访问”，确认框说明重新配对的要求；确认对象固定为打开时选中的设备。
- 多设备显示数量，“管理设备”直达远程设置。
- 收起后在统计入口前保留可展开的状态点；收起状态按任务保存在内存，连接设备变化后展开。
- 窄输入区把胶囊放到单独一行，运行状态与耗时、token 保持在下一行。长名称省略，悬停显示完整名称。
- 状态读取失败显示原因与重新读取入口；撤销失败保留确认框、目标设备及错误原因，支持再次提交。

业务逻辑审查核对了配对设备与在线设备的区别、初始读取与通知竞争、撤销目标、异步失败和任务完成时的确认生命周期。确认框提升到页面持有后，状态行切换会保留确认。代码设计审查核对了职责、事件订阅清理、主题 token、文案和布局复用。本次范围内的已知阻塞问题已处理。
