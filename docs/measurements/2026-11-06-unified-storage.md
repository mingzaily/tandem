# Tandem 统一存储验收（2026-11-06）

范围：`desktop/` 和相关文档。共享工作区保持 `main`，未提交、推送、切分支、stash 或 reset。三个 CLI 的配置与原生会话位置保持各自归属。

## 实现

| 内容 | 当前行为 |
|---|---|
| 用户配置 | `~/.tandem/config.toml`，Rust 解析、校验和写回。设置页提交变化的字段，`toml_edit` 保留顶层、行尾、表头及路径数组内的注释；删除路径所附注释移到数组末尾保留 |
| 程序状态 | `state.json` 保存置顶、归档、别名、项目顺序、侧栏状态与迁移版本。配置和状态均以同目录临时文件同步后原子替换，再同步目录 |
| 私密资料 | `remote.json` 保存手机配对与密钥，文件 `0600`、根目录 `0700`；自动生成 `.gitignore` 排除它、缓存、存储锁和临时文件。含私钥，保持本机存放，丢失后重新配对即可 |
| 队列和工作目录 | 队列与图片位于 `queues/`，无项目任务工作目录仍为 `conversations/`。工作目录中的产物按用户文件保存 |
| 页面 | 普通读写只用内存快照和后端命令。模型清单、用量、上下文窗口和安装状态仅在内存缓存；当前没有磁盘索引，未创建 `cache/` |
| 配置变化 | Rust 每 750ms 比较文件内容。有效手改广播到主窗口和菜单栏；错误文件保持原样、沿用进程内上次有效配置并提示，设置页也拒绝覆盖错误文件 |
| 首屏 | 创建窗口时注入快照和文档开始阶段的主题脚本，并设置原生窗口主题。首次升级先整理小型旧配置供首屏使用，再后台复制图片。发送等待队列恢复，草稿可继续输入 |
| 手机上下文 | 项目、别名、归档和对话目录直接来自 Rust。移除 `remote_update_context`；主窗口只补充系统显示语言这个内存观察值 |

入口为 `src-tauri/src/storage/`、`src/lib/storage.ts`、`src/preload-theme.js`。Tauri 调用集中在 `src/lib/api.ts`，界面通过原有 preferences/settings 接口读取内存视图。

## 迁移与交接

1. 取得 `~/.tandem/.storage.lock` 的进程级独占锁，检查本进程任务、队列和旧版 Tandem 进程。
2. 先由 Rust 合并旧 localStorage 中的配置与界面状态，首屏使用有效外观。已有 TOML 中明确填写的字段优先。
3. 独占队列读写门禁，复制旧 Application Support 的队列、图片和配对文件。复制前后比较源文件摘要；目标已有不同内容时保留双方并提示冲突。
4. 提交前重新读取 TOML，保留复制期间的手改内容。配置与状态均写入成功，最后记录迁移版本。
5. 写锁内重新加载远程密钥、配对列表和任务上下文，再放行等待中的写入，避免远程设置保存用旧内存覆盖刚迁入的资料。
6. 旧 localStorage 和旧 Application Support 文件原位保留一个版本。完成后重启跳过导入。失败时打开界面并保留重试入口，队列写入等待迁移完成。

迁移图片时配置快照保持可读，菜单栏创建不等待大图复制。观察配置文件的线程在迁移写锁之外等待。已有另一实例退出后，接手者重新读取其最后保存的配置与状态。

## 实际限制

同样受锁屏限制，尚未按可见窗口条件完成 release 启动和 `phys_footprint` 复测。上表是优化后的后端专项，不是整机启动时间或完整应用内存。本批未验证真实模型网络、手机在线重连和重配对。

localStorage 在测试前备份，结束后恢复，并以隔离 WebKit SQLite 的只读计数核对；测试会话、项目、数据和进程的最终清理记录见 [cleanup.json](assets/unified-storage/cleanup.json)。
