# 任务、对话、消息的命名

> **状态**：权威
> **读取时机**：新增或修改涉及这些概念的文案之前

| 概念 | 中文 | 英文 | 说明 |
|---|---|---|---|
| CLI 的一个 session | 任务 | task | 侧边栏里的每一行，可以并行推进 |
| 任务里来回交流这件事 | 对话 | conversation | 只在描述“跟 AI 对话”时使用 |
| 一条内容 | 消息 | message | 用户或 Agent 发出的一条内容 |
| 用户发一次到 Agent 答完 | 一轮 | turn | 主要在代码和技术文档里使用 |
| 工作目录 | 项目 | project | 侧边栏里的分组 |

- 面向用户时不要把 session 写成“会话”或“对话”。
- 代码和技术文档可以用 session，但要指清楚是 CLI 的原生会话。
- 动作写成动词加对象：`新建任务`、`停止生成`。
