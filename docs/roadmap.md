## 已完成

- 桌面端骨架：Tauri、React、设计 token
- Claude Code：任务列表、读取长任务、新建、续聊、停止
- 界面复刻第一版：侧边栏、工作组折叠、工具行、输入框、新建页
- 审批：工具授权、AskUserQuestion，"本任务都允许"
- 输入框第二版：运行状态行（状态、用时、输出 token）、权限模式、模型和推理强度、所在项目、套餐用量、上下文圆环
- 附件：`+`、粘贴图片、拖入窗口。图片随消息发送，其他文件按路径交给 agent，只放行这一个文件的读取
- 图片查看：点击放大，滚轮缩放 1–8 倍，拖动平移，双击切换，Esc 关闭
- 外观第二版：暖色主题值、侧栏毛玻璃、新建页 logo 和建议、新建页与对话页同宽、标题栏的侧栏开关和前进后退、等待确认的标记
- 添加项目：新建页和设置页都能选择文件夹，没跑过 `claude` 的目录也能新建任务
- 侧边栏第三版：置顶、归档、重命名、任务菜单（行尾、右键、标题栏）、拖动调宽、底部卡片
- 分支和 worktree：新建页显示当前分支，可以勾选在新 worktree 中运行，任务归到原项目下
- 设置页第一版：语言、发送快捷键、主题、字号、侧栏透明、CLI 状态、项目、关于
- 单写入者保护：任务开在终端或其他程序时，侧栏有标记，发送前要确认，后端也会拦
- Codex 接入：任务列表和历史、新建和续接、确认和提问、模型和推理强度、用量、附件、停止
- 项目范围：只扫描已加入的项目，设置页列出发现的项目。首次启动自动加入最近 30 天用过的
- 对话分组：不选项目的任务放在 `~/.tandem/conversations/` 的独立子目录，目录可以改
- 跟随别处的任务：任务开在终端或其他程序时，文件变了就刷新
- Agent 设置：状态、版本和登录，点按钮才安装或登录。Pi 不帮配
- 模型面板：按 Agent 分栏，带说明和推理强度滑块
- 主题：Tandem、朴素和另外 7 个内置配色
- 菜单栏和通知：点图标打开面板，每个 Agent 一根额度管，5 小时和本周合在一起，液位取先用完的那个；列出进行中的任务；任务完成或等确认时通知；关窗口后留在后台
- 项目排序：侧边栏拖动项目调整顺序，也可以 Option + 方向键
- 压缩标记：CLI 压缩对话的地方显示分隔线，不再把摘要显示成用户消息
- 推理强度：显示每个模型实际的默认级别，模型面板的选中和悬停照 Cindy 做
- Pi 接入：任务列表和历史、新建和续接、模型和推理强度、附件、停止、扩展对话框
- 运行中的信息：运行状态行可以点开生成速度卡片，有曲线、平均和峰值；上下文圆环可以点开，Claude 任务可以手动压缩
- 对话里的标记：停止显示成“已中断”，CLI 运行中插入的消息也会显示
- 手机访问的桌面端：设置页的远程、配对、撤销，默认关闭。协议见 [relay-protocol.md](relay-protocol.md)
- 远程连接闭环：准入确认后展示配对码和交付令牌、违规连接断开、相对配对期限、重连快照计时、长期令牌重登记
- 消息队列：运行时发送入队，Rust 按任务持久化；支持指针和键盘排序、编辑、删除、折叠；正常结束自动续发，停止、出错和重启后暂停，可继续发送；附件和发送选项随条目保存，菜单栏显示排队数
- 单个任务生成标题：标题栏和任务菜单入口，独立请求模型并通过三种 CLI 的原生改名接口保存，任务消息保持原样
- Codex App 附件消息显示：提取附件封装中的用户正文，图片和文件标签分别显示

## 已知问题

- 发送后立刻停止，如果 CLI 还没写入，这条提示词不会留在任务里。
- 列表还包含 Tandem 之外的程序用 `claude` 跑出来的任务，比如旧客户端的临时目录，需要过滤规则。
- 长消息和工具输出按固定上限截断，还不能查看全文。
- 拖入窗口的真实手势还没有自动测试：测试只走到拖入之后的同一段代码。
- 只有图片的消息没有标题，侧边栏显示"未命名任务"，除非 CLI 自己生成了标题。
- 手动重命名、置顶和归档只在 Tandem 里生效；“生成标题”保存到 CLI 的原生任务中，终端可以读取。
- 只能显示分支，不能切换。worktree 由 CLI 创建，Tandem 不负责清理，它们留在项目的 `.claude/worktrees/` 下。
- 语言要重新打开 Tandem 才生效。
- Codex 没有"本任务都允许"：它的授权只在当前进程有效，而 Tandem 每轮一个进程。需要少打扰时用"自动审批"。
- Codex 任务只读最近 3000 条记录，上下文圆环要跑完一轮才显示，最多列出最近 200 个任务，不能用 worktree 开关。
- 任务开在 ChatGPT 里时，Codex 不允许续接，要先在那边关掉。
- Pi 没有写入标记，开在终端里的 Pi 任务查不出来，也拦不住同时写入。
- Pi 没有套餐用量可读，也没有权限确认，工具直接运行。
- 单写入者保护只防 Tandem 这一侧：Tandem 运行时用户在终端续接同一个任务，拦不住。
- 上下文圆环要等这个模型跑完一轮才知道窗口大小，之前不显示。
- 语音输入和 Plan 模式没有做。
- Codex 和 Pi 不记录停止，重启后“已中断”标记会消失。
- 手机访问还没在真机和公网 `wss://` 上验证过。
- 手机看不到待发送队列。
