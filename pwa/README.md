# Tandem PWA

React、Vite、TypeScript 手机客户端，引用桌面端的 design token。任务列表和消息列表虚拟化，Markdown、高亮和扫码按需加载。消息与运行快照只存内存；IndexedDB 保存配对身份、准入令牌及不可导出的 P-256 签名私钥。

## 运行

需要 Node 24 和 pnpm 10。

```sh
pnpm install
pnpm dev
```

按 [relay README](../relay/README.md) 启动 Rust relay 与 fake-host，将开发工具输出的 `tandem-pair:` 配对码粘贴到页面。localhost 可以使用 HTTP / WS；手机使用 HTTPS / WSS。WebCrypto 和相机要求安全上下文。

**iOS 先添加到主屏幕，再从主屏幕打开并配对。** Safari 和主屏幕 PWA 使用独立存储。主屏幕图标提供 180、192、512 像素 PNG，标志与桌面端一致。

## 界面与操作

- 配对首屏展示设备名称、配对码入口及六位确认码，引导在电脑上核对并允许。
- 任务按项目分组，沿用桌面端的 14px/medium 标题、CLI 图标与颜色；等待确认时在右侧显示状态圆点，运行时图标呼吸。支持按任务标题、项目路径和 CLI 在本机搜索；项目可折叠，搜索时展开匹配分组，清除搜索后保留原折叠选择。刷新连接与重新配对收进连接菜单。
- 消息渲染 Markdown、GFM、代码高亮。原始 HTML 跳过，远程图片只显示替代文字，链接在新页面打开。
- 工具结果合并到对应工具行，文件操作优先显示文件名，MCP 显示“调用 服务器 · 可读工具名”，原始输入和输出通过点按展开；运行中的动作段默认预览最近 5 条活动；点击组头完整收起，再次点击展开全部，继续输出时保持用户选择。助手进度结束前一动作段，只有尾部动作段继续转圈。整轮结束后将过程收进“已处理 X”，最终回复留在外面；展开状态按任务保存在内存，超过 80 条的工作清单使用 420px 虚拟滚动区域。压缩与中断保留独立提示。
- 模型按 Agent 分组，强度和权限使用底部面板，选中行有底色和勾选，入口展开时保持按下反馈。模型 ID 按原生记录匹配菜单别名，模型、强度和权限按任务保存；新建页保留每个 Agent 的独立默认值。读取模型列表或恢复连接保留当前选择。强度显示模型的实际默认级别，选择该级别时继续由 CLI 决定。完全访问需要在面板内确认。
- 输入卡片沿用桌面端 12px 圆角、续聊最小 112px、新建最小 140px 和 24px 正文内距；输入保持 16px，适配手机键盘，随文字自动增高至 240px。发送按钮视觉大小为 28px，触控区域为 44px；模型、强度、权限和项目选择放在输入卡片内，窄屏分行显示。运行中编辑草稿时回车换行。未发送文字按任务保存在内存，发送成功只清除提交的那份草稿。
- 确认和提问卡片显示在输入框上方，保留 10px 间距；输入框、草稿和停止入口持续保留，长卡片独立滚动。回答提交后等待桌面端的已处理事件或新快照移除卡片；失败在卡片内显示原因并恢复操作。中文输入法确认候选词保留在回答框中。单选选项点击后直接推进；自定义回答先选择入口再显示输入框，“返回选项”收起输入并保留草稿，纯输入题直接显示。Pi 普通选择框保留扩展选项，`pi-ask-user` 的固定自由回答项归一化为本地化入口，用户提交后由宿主桥接原生选择和后续输入请求；Codex 跟随原生 `isOther`，Claude 使用页面自定义入口，保持单选、多选和自由回答的原生提交语义。运行状态显示用时及输出 token，快照和实时事件携带桌面端的开始时间与已运行时长，手机用单调时钟延续计时，重连和两端系统时钟差均保留运行用时。并行工具按仍未结束的调用显示状态。
- 中断标记与桌面端共用 CirclePause 图标和暂停颜色；运行状态使用“正在思考…”“正在回复…”“正在调用工具…”“等你确认…”，输出单位为 `tok`。连接正常时保留内容空间，连接中、离线和错误时显示相应提示。
- 当前轮失败显示在输入框上方，使用中性表面、错误图标和可展开的错误详情；关闭后保留任务内容。消息同步失败时保留已收到的输出，并恢复输入操作。

已配对会话收到 `4411`（本次会话被断开）或 `4429`（连接／准入限额）时保留身份，按 1.5 秒起、最大 30 秒的指数退避重连，握手成功后重置。`4400`、`4401` 停止重试并提示检查协议版本与配对信息，`4410` 表示客户端未配对或已撤销，清除本机身份并提示重新配对。配对连接单次尝试，已接收的最终回复完成解密后再处理关闭；一次性配对令牌由用户重新发起使用。

任务按 `host.info.projects` 的顺序分组，`conversationRoots` 中当前和历史工作区下的任务归入“对话”。同一轮连续的文字或思考增量合并为一个事件，工具和其他事件保留边界。运行快照携带原始提示词，实时开始和结束事件携带提示词与实际 Agent；消息流以轮次、主机时间戳和工具 ID 合并历史与实时内容，保留更完整的已写入文字和附件占位。每轮实时行使用独立 ID，已结束轮次在成功读取原生记录后移除。

页面恢复可见、系统恢复页面或网络重新在线时，重新核对任务、运行快照和当前会话。恢复过程按连接分代，同连接的并发恢复合并执行；旧连接的迟到回复保持隔离，桌面端重启后使用新事件序号。取快照期间缓冲的结束事件在快照已移除该轮时仍处理一次。同步失败显示“重新同步”，保留草稿和已有内容。关闭连接前先完成已接收帧的解密；旧连接迟到的解密结果保持隔离。

深色模式跟随系统，布局使用安全区和 VisualViewport 高度适配键盘。支持分页、新建、发送、停止、单选、多选和自由回答，以及断线重连和快照补齐；撤销后停止重连，可重新配对。Enter 发送，Shift-Enter 换行，输入法确认候选词、WebKit 的 229 按键码和组合结束后 80ms 内的回车保留在输入框中。新建任务从 started 事件或运行快照取得 taskId 后立即展示实时内容和确认卡，原生任务列表稍后补全标题；启动失败恢复原草稿。目录、权限与单写入者规则最终由桌面端裁决。

## 检查

跨项目完整检查在仓库根目录运行 `node .github/scripts/verify.mjs`，包括根路径和官网子路径的浏览器验收；追加 `--image` 验证本机容器。安装浏览器、截图留存与 CI 门禁见 [CI 与本地验证](../docs/dev-rules/ci-validation.md)。

协议与恢复测试覆盖工具合并、折叠边界、历史与实时去重、快照期间轮次结束、桌面重启序号、等待时的输入和停止入口、旧连接错误和关闭前最后一帧的异步解密。新建任务用例覆盖应答先于原生登记、started 先于应答、快照识别任务和早期启动失败；relay 的定向用例串联真实加密连接与延迟启动的 fake-host。协议与浏览器测试复用 `relay/dev/` 的工具，先在 `relay/` 安装开发依赖。

```sh
pnpm typecheck
pnpm test
pnpm build
SHOTS=/绝对路径/pwa- pnpm test:browser
```

`test:browser` 先编译 Rust relay，再构建生产 PWA，使用本机无头 Chrome 与独立浏览器上下文。每个组合都测试配对、六位码、分组、Markdown 安全边界、折叠、面板、完全访问、确认、提问、新建、重载、撤销和重新配对，结束后关闭服务与浏览器。

| 视口 | 主题 |
| --- | --- |
| 390 × 844 | 浅色、深色 |
| 360 × 740 | 浅色、深色 |

每组生成 `pair`、`pair-code`、`list`、`task`、`effort`、`permission`、`permission-recovered`、`question`、`models`、`revoked`、`connecting`、`offline` 十二张截图。文件名为 `<SHOTS><宽>x<高>-<主题>-<页面>.png`，共 48 张。`permission-recovered` 验证等待确认时重载页面及手机时钟偏差一小时后仍延续运行用时；连接场景验证正常连接时状态行消失，重连和离线时提示可见。省略 SHOTS 时截图使用临时目录，测试结束清理；留存截图请指定绝对路径前缀。

协议测试使用仓库固定向量验证配对、握手、签名、密文、分片、重放和顺序；运行状态测试覆盖工具合并、折叠边界、旧连接错误和关闭前最后一帧的异步解密。

容器已经启动且使用测试令牌 `container-fixture` 时，可运行：

```sh
PWA_ORIGIN=http://127.0.0.1:映射端口 pnpm test:container
```

此测试验证容器健康接口、CSP、生产静态页面与真实 WebSocket 配对。真实调试版桌面端互通在 `relay/` 运行 `pnpm interop`，使用替身 CLI，检查并清理测试 `remote.json`，恢复 localStorage。

## 部署与缓存

官网手机端入口为 `https://mingzaily.github.io/tandem/app/`。`pwa/` 保持顶层独立项目，由 Pages 发布脚本以 `/tandem/app/` base 构建，再组合到官网产物；中转由使用者自己部署，地址来自配对码。

默认 `pnpm build` 生成 HTTPS 根路径使用的 `dist/`，镜像继续携带这份构建结果。中转域名的 `/` 由 relay 返回部署状态页，手机端入口是官网 `/tandem/app/`。子路径构建使用 `pnpm build --base=/tandem/app/`；图标、manifest、安装入口和 Service Worker 跟随 base。离线缓存按部署路径独立命名，更新时只清理同一应用路径的旧版本。用户部署、反向代理、手机配对与排错文档位于 [site/src/guide/](../site/src/guide/index.md)。

在 `site/` 运行 `pnpm build:pages && pnpm test` 构建并检查组合产物；在 `pwa/` 运行 `pnpm test:hosting` 验证官网入口、安装资源、离线缓存与根路径自托管。完整协议浏览器测试可设置 `PWA_BASE=/tandem/app/`，使用已按该 base 构建的产物运行 `pnpm exec tsx test/browser.e2e.ts`。

Service Worker 只在生产构建启用，缓存固定外壳 HTML、JS、CSS、图标和 manifest；任务、WebSocket 和额外网络响应只在内存中处理。旧窗口关闭后新版本接管，离线可打开外壳，任务需要电脑在线重新获取。

生产首屏 JS gzip 约 101 KiB，Markdown / 高亮约 105 KiB、扫码约 48 KiB 单独加载。手机硬件、iOS 安装与存储隔离、相机、软键盘、后台恢复及公网 WSS 需要真机验收。
