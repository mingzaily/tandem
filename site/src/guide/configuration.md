# 环境变量

| 变量                       | 本地默认值           | 容器值 / 用途                                                |
| -------------------------- | -------------------- | ------------------------------------------------------------ |
| `TANDEM_RELAY_HOST_TOKEN`  | 必填                 | 足够长的随机部署令牌，与桌面端相同                           |
| `TANDEM_RELAY_DATA_FILE`   | `./data/tokens.json` | `/data/tokens.json`，持久化长期准入令牌的 SHA-256 与房间映射 |
| `HOST`                     | `127.0.0.1`          | `0.0.0.0`，容器内监听地址                                    |
| `PORT`                     | `8787`               | HTTP 和 WebSocket 共用端口                                   |
| `TANDEM_RELAY_TRUST_PROXY` | 关闭                 | 恰好为 `1` 时信任 `X-Forwarded-For` 的最后一段               |
| `TANDEM_RELAY_STATIC_DIR`  | 关闭                 | `/pwa`，可选 PWA 构建目录；本地设置为绝对路径即可合并托管    |

服务单实例运行，独占数据目录。配对令牌只在内存中保留，最多五分钟；长期令牌原子写入磁盘，权限为 `0600`。

代理只应连接受保护的内部端口。启用信任代理前，确认入口网关覆盖或追加可信的来源地址，外部无法绕过网关连接 8787。存在多级代理时，最后一段必须由紧邻中转的可信网关写入，详见[代理示例](./proxy.md)。

WebSocket 路径固定为 `/ws`，健康检查路径固定为 `/healthz`。中转每 30 秒发送 ping，90 秒收不到 pong 时关闭连接。
