# 桌面端使用

本页从打开 macOS 上的 Tandem 开始。准备好你要使用的 Claude Code、Codex 或 Pi，模型服务与账号沿用各 CLI 的设置。

## 确认 Agent 状态

打开“设置 → Agent”，查看本机工具的安装和登录状态。Claude Code 和 Codex 提供安装与登录入口，操作由你点击后执行。Pi 的模型和密钥在 Pi 自己的工具环境中配置。

Tandem 从登录 shell 的环境中查找 CLI，使用 CLI 已有的配置和登录状态。

## 新建任务

1. 点击“新建任务”，选择项目；需要加入新目录时，点击“选择文件夹…”。也可以使用独立的对话目录。
2. 选择 Claude Code、Codex 或 Pi，再按需要选择模型、推理强度和权限模式。可用选项随 Agent 与模型变化。
3. 输入需求并发送。可以粘贴图片或拖入文件，为任务补充上下文。

选择完全访问前，先确认当前任务适合使用的权限范围。工具最终按对应 CLI 的权限方式运行。

## 阅读与继续任务

侧栏按项目列出任务。打开一条任务，可以读取历史消息，查看 Markdown、代码、工具调用与工作过程。已完成的工作可以折叠，展开后查看细节。

继续发送消息时，Tandem 续接这条任务。你也可以置顶常用任务、归档暂时不用的任务，或为任务重命名。任务菜单中的“复制终端续接命令”用于回到 CLI 继续工作。

## 安排待发送消息

Agent 运行期间发送的新消息进入队列。你可以调整顺序、编辑内容或删除条目，每条消息保留入队时的附件和发送选项。

当前一轮正常结束后，队列按顺序继续发送。停止生成、任务出错或重启应用后，队列暂停；检查待发送内容后，点击“继续发送”恢复。

## 处理确认与提问

Agent 请求工具授权或需要回答问题时，Tandem 会显示对应卡片。先查看工具、参数与作用范围，再选择允许、拒绝或提交回答。

“本任务都允许”只作用于卡片列出的范围，保留到 Tandem 退出。具体可用的授权方式取决于 Agent。

## Agent 之间的差异

| Agent       | 使用时需要了解的差异                                                                                                                                |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude Code | 提供工具确认、提问与“本任务都允许”，新建任务可选择新的 worktree。                                                                                   |
| Codex       | 提供工具确认与提问；自动审批和完全访问按所选权限运行。任务由其他程序占用时，先在该程序中结束操作。                                                  |
| Pi          | 模型与思考等级来自 Pi 的配置。Pi 的工具直接运行，扩展需要输入时可以显示对话框；目前无法检测它在其他程序中的任务写入状态，同一任务请在一个位置操作。 |

## 菜单栏与通知

菜单栏面板显示进行中的任务和 Agent 提供的额度信息。开启“关闭窗口后留在菜单栏”后，关掉主窗口，任务继续运行。

在设置中开启“任务完成时通知”，窗口位于后台时，任务完成或等待确认会发送系统通知。

## 从手机继续

需要远程访问时，按[手机访问部署指南](./quick-start.md)准备中转，再完成[手机配对](./pairing.md)。电脑上的 Tandem 与 CLI 继续负责执行，手机用于查看和操作同一批任务。
