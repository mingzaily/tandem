# 认识 Tandem

Tandem 是一个轻量的 AI 编程桌面客户端，把你自己安装的 Claude Code、Codex 和 Pi 放进同一个窗口。你可以按项目整理任务，选择模型和推理强度，阅读工作过程，并继续在终端里开始的任务。

Tandem 基于 Tauri 和 Rust 构建，桌面端当前在 macOS 上使用。模型和登录状态由各 CLI 提供，沿用你已有的工具环境。

## 在桌面上能做什么

- **整理任务。** 按项目查看三个 Agent 的任务，搜索、置顶、归档和重命名，从已有记录继续，或新建任务。
- **选择工具。** 在输入框中切换 Agent、模型、推理强度和权限；实际选项由对应 Agent 的能力决定。
- **跟进工作。** 阅读 Markdown、代码和工具结果，展开工作过程，查看运行用时、输出 token 和可用的上下文信息。
- **准备后续消息。** 运行中把消息加入待发送队列，编辑、排序或删除；正常结束后依次发送，停止或出错后暂停。
- **处理确认和提问。** 在卡片里查看工具请求并作决定，回答 Agent 提供的问题。Claude Code、Codex 与 Pi 的能力差异见[桌面端使用](./desktop.md#agent-之间的差异)。
- **附上上下文。** 粘贴图片、拖入文件，让 Agent 在自己的项目环境中处理任务。

菜单栏面板可以查看进行中的任务和可用额度。开启“关闭窗口后留在菜单栏”后，关掉主窗口，任务继续运行。

## 和终端共用任务

已发送任务的记录保存在各 CLI 自己的文件中。Tandem 读取这些原生记录，你可以从桌面端打开，也可以复制终端续接命令回到 CLI。

界面偏好、待发送草稿和配对信息由 Tandem 保存。移除 Tandem 的应用数据会清除这些内容，各 CLI 已保存的任务记录继续保留。

## 手机访问是可选功能

桌面端的日常操作直接在本机完成。需要离开电脑继续工作时，可以开启手机访问：在自己的服务器上部署中转，<a href="../app/" target="_self">打开官网手机端</a>并与电脑配对。公共手机端连接配对码中的中转地址。

配对后，手机可以查看项目与任务、新建任务、发送消息、停止生成，并处理确认和提问。电脑需要保持运行和联网，Agent 始终在电脑上工作。

手机与电脑之间的任务内容端到端加密，中转负责准入和转发密文。手机丢失或停止使用时，在电脑上撤销设备即可。详见[安全模型](./security.md)。
