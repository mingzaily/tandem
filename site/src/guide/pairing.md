# 桌面端与手机配对

## 电脑上

1. 打开 Tandem 的“设置 → 远程”，在“中转服务”中填写中转地址 `wss://relay.example.com/ws`，部署令牌填写服务器的 `TANDEM_RELAY_HOST_TOKEN`，点击“保存更改”。
2. 开启“允许手机访问”，等待状态显示“已连接”。
3. 点击“已配对设备”右侧的“配对新设备”。配对码使用一次，最长五分钟有效；点击“取消配对”可提前结束。

## 手机上

1. <a href="../app/" target="_self">打开官网手机端</a>，也可以使用自托管中转附带的 `https://relay.example.com` 页面。
2. **iOS：先通过 Safari 的“分享 → 添加到主屏幕”安装，然后从主屏幕打开 Tandem。** Safari 和主屏幕 PWA 使用各自的存储，在 Safari 中配对的身份无法带入主屏幕 PWA。
3. Android 使用浏览器菜单中的安装应用或添加到主屏幕，再从安装后的应用打开。
4. 输入设备名称，粘贴电脑给出的 `tandem-pair:` 配对码，或允许相机扫描电脑上的二维码。
5. 核对手机与电脑显示的六位确认码。两边数字一致时，在电脑弹窗中允许配对。

配对后，手机会保存自己的设备身份并重新建立加密连接。之后直接从主屏幕打开，即可读取电脑上的项目和任务。

手机和平板可以分别配对、同时连接同一台电脑。配对码使用一次；为第二台设备重新生成一份。每台设备拥有独立身份，电脑上可以分别撤销。切换到另一域名的手机端时，需要重新配对。

## 日常使用

任务按电脑上的项目顺序分组，当前和历史对话工作区中的任务统一放在“对话”下。打开任务可查看历史与工作过程，发送消息、停止生成、确认工具请求或回答提问。新建任务只能选择桌面端已添加的项目或对话目录。

模型、推理强度、权限在输入框的底部面板中选择。手机可以选择完全访问；请按自己的信任范围使用。检测到任务在其他位置运行时会显示状态，手机等待其完成后再发送。Pi 的外部运行状态需要手动核对，同一任务请在一个位置操作。

设备丢失或停止使用时，在电脑上撤销对应手机。手机连接立即关闭，令牌失效。重新授权时，从电脑生成新的配对码。
