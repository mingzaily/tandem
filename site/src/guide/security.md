# 安全模型

## 内容在哪里

任务内容保存在用户自己的 CLI 原生文件中。PWA 的任务与运行数据只放在内存；IndexedDB 保存配对身份、准入令牌和不可导出的设备签名私钥。清除手机站点数据后，需要重新配对。

中转核对令牌、转发密文、报告上下线。它保存长期准入令牌的 SHA-256 与房间映射，看不到消息、工具参数、提问和回答，也保存不了任务内容的明文。

中转仍能观察 IP、连接时间、房间与消息大小等元数据。日志仅记录连接事件与错误码。

## 两层保护

HTTPS/WSS 保护传输和 PWA 页面交付。手机与桌面端另外通过签名、密钥交换与 AES-GCM 建立端到端加密通道，每次重连重新握手。配对密钥留在两端，用户通过六位确认码核对设备。

部署令牌负责桌面端准入，客户端令牌绑定房间。中转把令牌哈希原子保存为权限 `0600` 的文件，配对令牌最多在内存保留五分钟。

官网提供公共 PWA 静态页面，浏览器连接配对码中的自建中转。部署令牌保存在使用者的中转和桌面端，设备私钥保存在手机，任务在桌面端处理。GitHub Pages 只交付客户端文件。

官网手机端与文档使用同一来源，浏览器存储也按来源隔离；两部分的发布代码都属于客户端的信任边界。手机端的离线缓存限定在 `/tandem/app/`。请保护提供 PWA 页面和 JS 的网关与服务器。端到端加密依赖用户运行可信的客户端代码；被篡改的网页可以在内容加密前读取内容。

## 手机权限

手机与电脑可选择相同的 Agent 权限，包括完全访问。授权结果最终由桌面端校验。Agent 的文件和命令权限由所选模式决定；完全访问允许 Agent 访问电脑上的文件并运行命令，请按自己的信任范围授权。

手机端提供查看任务、发送消息、停止生成、处理确认与提问等操作。安装和登录 CLI、修改 Tandem 设置、管理配对设备在电脑上完成。新建任务的目录从已添加项目或对话目录中选择。

检测到任务在其他位置运行时，手机会等待其释放后再发送。Pi 的外部运行状态目前需要手动核对，同一任务请在一个位置操作。手机丢失时，在电脑上撤销设备即可同时关闭连接并使其准入令牌失效。

Tandem 使用用户自己安装的 CLI，不引入账号、遥测、崩溃上报或自动更新。
